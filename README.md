## 特点

- 纯静态单文件，背景壁纸、品牌图标、客服二维码**全部 base64 内联**，不依赖任何外部资源——丢到任意静态托管即可运行（GitHub Pages / Vercel / Netlify / 对象存储静态站均可）。
- 移动优先，自动适配手机与电脑窗口；全屏背景图 `cover` 铺满不拉伸；卡片采用毛玻璃（backdrop-filter）质感；不支持毛玻璃的旧浏览器自动降级提高不透明度保证可读。
- 客服微信：MTQQ（点击页脚弹出二维码）。

## 本地预览

直接用浏览器打开 `index.html` 即可，无需服务器。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个空仓库（如 `4year-nav`）。
2. 把本目录内容推送到该仓库的 `main` 分支。
3. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)` 目录 → Save。
4. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即为线上链接。
